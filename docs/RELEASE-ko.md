## ColorOS Mod 1.0.36-ko.1 — 한국어판 테스트 릴리스

원본 1.0.36을 기반으로 한 한국어 전용 포크입니다. 원작자의 공식 한국어판은 아닙니다.

### 변경 내용
- 기본 문구 146종을 코드 151곳에 적용했습니다. 9개 설정 분류, 도움말, 오류·권한 안내, 접근성 설명, 확인·취소, 재시작 메뉴, 앱 목록과 내보내기 안내를 포함합니다.
- 노이즈 제어 모드, 잠금 화면 안내, 플로팅 창 상태 등 모듈이 시스템 화면에 표시하는 문구도 번역했습니다.
- 앱 이름, 폴더 표시 이름과 지역 안내를 번역했습니다. 실제 폴더명과 패키지 ID, 설정 키, 후킹 대상은 유지합니다.
- 한국어 README, 원본 중국어 README 보존, APK 내부 MIT 저작권 고지, 번역 회귀 검사와 APK 검증을 추가했습니다.

### 설치
`ColorOS-Mod-1.0.36-ko.1-debug.apk`를 설치하고 LSPosed에서 모듈과 적용 범위를 확인하세요. 기기 언어와 관계없이 한국어로 표시됩니다. `SHA256SUMS.txt`와 `signature.txt`에서 파일 및 공개 서명 인증서를 확인할 수 있습니다.

**이 파일은 디버그 인증서로 서명된 설치 가능한 Debug APK입니다. 정식 배포용 개인 서명키를 사용하지 않았으며 디버깅이 허용됩니다.** 원본과 같은 패키지 ID(`com.rikumi.colorosmod`)지만 서명이 다를 수 있어 덮어쓰기 설치가 실패할 수 있습니다. 기존 설정을 기록한 뒤 원본 제거가 필요할 수 있으며, 제거하면 모듈 설정이 사라질 수 있습니다. CI 서명키는 다음 빌드에서 달라질 수 있으므로 향후 버전도 재설치가 필요할 수 있습니다.

### 검증 범위
정적 번역 검사, 6개 회귀 테스트, APK 서명·버전·한국어 앱 이름·Xposed 메타데이터·라이선스 검사를 수행합니다. 일반 Android 에뮬레이터에서 홈 화면과 9개 설정 화면의 라이트·다크 모드를 탐색하고 표시 문구와 비정상 종료 여부를 검사합니다. 화면 검사 자료는 `ui-verification.zip`에 있습니다.

**실제 ColorOS/OxygenOS 기기의 LSPosed 후킹 동작까지 검증한 릴리스는 아닙니다.** 원작의 대상은 Android 16 기반 ColorOS/OxygenOS/realme UI입니다. 중요한 데이터가 있는 기기에서는 백업 후 필요한 기능만 하나씩 켜세요.

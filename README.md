# ColorOS Mod 한국어

[rikumi/coloros-mod](https://github.com/rikumi/coloros-mod)의 **1.0.36 기반 한국어 전용 포크**입니다. 원작자의 공식 한국어 배포판은 아닙니다.

- 한국어판 버전: **1.0.36-ko.1** / versionCode **10037**
- 모듈 ID: `com.rikumi.colorosmod` — 원본과 동일합니다.
- [한국어 APK 릴리스](https://github.com/devuterian/coloros-mod/releases)
- [원본 중국어 안내](README.zh-CN.md)

## 한국어 번역 범위

설정 화면의 제목·기능 이름·설명, 확인·취소 버튼, 접근성 설명, 루트 권한과 오류 안내, 재시작 메뉴, 사용 중지된 앱 목록과 내보내기 안내, 내보낸 스크립트의 설명을 한국어로 옮겼습니다. 모듈이 표시하는 노이즈 제어 모드·잠금 화면 안내·플로팅 창 상태 문구도 포함합니다.

기본 번역 146종을 코드의 151곳에 적용하고, 앱 이름·폴더 이름의 설명·지역 표시도 번역했습니다. 기기 언어와 관계없이 한국어로 표시되는 빌드입니다. 다른 앱이 제공하는 앱 이름, 실제 폴더 경로, API 이름과 단위는 원래 값을 유지합니다. 외부 운영체제 자체를 번역하는 모듈은 아닙니다.

중국어 ROM의 메시지를 감지하는 내부 문자열 5개는 기능이 깨지지 않도록 유지했습니다. 설정 키·패키지 ID·후킹 대상·셸 명령은 변경하지 않았습니다. 소스 주석과 개발 로그 전체를 번역한 것은 아닙니다.

## 설치 전 확인

실제 기능을 사용하려면 루팅된 기기와 이 모듈의 현대식 libxposed API를 지원하는 LSPosed 계열 프레임워크가 필요합니다. 모듈 메타데이터의 최소 API는 101, 대상 API는 102입니다.

원작자는 OPPO Find X8s에서 테스트했으며 Android 16 기반 ColorOS/OxygenOS/realme UI를 대상으로 합니다. 다른 기기·ROM에서의 작동을 보장하지 않습니다. 한국어판의 빌드·정적 검사·일반 Android 에뮬레이터 UI 검사는 실제 ColorOS 기기의 후킹 기능 검증을 대체하지 않습니다.

**백업하지 않은 주 사용 기기에서 모든 기능을 한 번에 켜지 마세요.** 숨긴 앱, 잠금 화면, 시스템 프로세스에 영향을 주는 기능이 포함됩니다. 기능을 하나씩 켜서 확인하는 편이 안전합니다.

## 설치 방법과 서명 주의사항

1. 릴리스에서 `ColorOS-Mod-1.0.36-ko.1-debug.apk`를 받아 설치합니다.
2. LSPosed에서 모듈을 활성화하고 모듈이 지정한 적용 범위를 확인합니다.
3. 필요한 기능을 선택한 뒤 적용 대상 앱을 재시작합니다. Zygote 재시작이 필요하다고 표시된 기능은 해당 재시작이나 기기 재부팅을 진행합니다.

이 APK는 원본 프로젝트와 마찬가지로 **CI에서 생성한 Android 디버그 인증서로 서명한 설치 가능한 Debug 빌드**입니다. 정식 배포용 개인 서명키로 서명한 APK가 아니며 디버깅이 허용됩니다.

원본과 패키지 ID는 같지만 서명이 다를 수 있어 덮어쓰기 설치가 실패할 수 있습니다. 이 경우 기존 모듈의 설정을 기록하고 원본을 제거한 뒤 한국어판을 설치해야 합니다. 앱 제거 시 모듈 설정이 삭제될 수 있습니다. 원본과 한국어판을 동시에 설치할 수는 없습니다.

현재 CI의 디버그 서명키는 빌드마다 바뀔 수 있습니다. 따라서 다음 한국어판도 재설치가 필요할 수 있으며, 계속 업데이트할 정식 배포에는 별도로 안전하게 관리하는 고정 서명키가 필요합니다. 릴리스 파일의 `signature.txt`에서 인증서 SHA-256을 확인할 수 있습니다.

## 주요 기능

### 홈 화면

아이콘과 이름 사이 간격, 앱 서랍의 한 줄당 아이콘 수, 글자 색인 스크롤, 홈 화면과 독의 간격, 편집 모드 배경, 길게 누르기 메뉴의 크기·흐림·밝기, 폴더 배경과 애니메이션 시간을 조절합니다.

### 제어 센터

알림·제어 센터의 배경 밝기·흐림·축소 비율, 통신사와 상태 아이콘 표시, 분리형 패널 전환, Wi-Fi·블루투스 이름 표시, OxygenOS 모서리, 통합형 패널 날짜·시간, 음량 바의 노이즈 제어 버튼을 설정합니다.

### 알림 센터·상태 표시줄

알림을 밀어서 지우거나 펼치는 동작, 무음 알림 영역의 제목 크기, 알림 여백, 상태 표시줄 가사, 다른 가사 오버레이와의 겹침, 플루이드 클라우드 표시 중 배터리 잔량을 조절합니다. 가사 표시는 플레이어의 ColorOS `MediaSession metadata.lyricInfo` 지원이 필요하며 Meizu 방식은 지원하지 않습니다.

### 잠금 화면

잠금 해제 상태의 전원 종료 인증, 비밀번호 밀어서 입력, 비밀번호 화면에서 뒤로 가기, 빛 효과, 배경 밝기, 잠금 화면 알림 위치와 충전 애니메이션을 설정합니다.

### 숨긴 앱

최근 앱에서 숨긴 앱 표시, 숨긴 앱 폴더의 인증 생략, 두 손가락 벌리기 동작, 제목의 폴더 이름 표시, 연락처·Gboard·GhostLock 아이콘 숨기기를 설정합니다. 인증 생략 기능은 개인정보 보호 수준을 낮출 수 있습니다.

### 플로팅 창

최근 앱 목록에서의 표시, 가장자리에 숨긴 채 실행, 음소거, 흰색 세로 막대 표시, 가로 앱의 종횡비, 가장자리 위치와 최대 크기를 설정합니다. 변경 후에는 Zygote 재시작이 필요합니다.

### 내비게이션·제스처

하단 제스처 영역의 높이, mBack, 터치가 아래 앱으로 전달되는 동작, 회전 제안 버튼, 길게 누르기 인식 시간, 애니메이션 배율, 제스처 바 너비와 효과, 최근 앱 정리 동작을 설정합니다.

### 저장 공간 관리

`Alarms`, `Audiobooks`, `Movies`, `Notifications`, `Podcasts`, `Recordings`, `Ringtones` 폴더의 자동 생성을 막습니다. 표시 이름에 한국어 설명을 붙였지만 실제 폴더 이름은 바꾸지 않았습니다. 원본 로직은 비어 있는 폴더만 삭제하며 내용이 있는 폴더는 그대로 둡니다.

### 사용 중지된 앱

다른 방법으로 사용 중지했거나 현재 사용자에서 제거한 앱을 확인하고, 같은 작업을 수행하는 ADB 스크립트로 내보냅니다. 이 화면 자체에서 앱을 직접 사용 중지하지는 않습니다. 스크립트는 시스템을 불안정하게 만들 수 있으므로 중요한 데이터가 없는 초기화된 테스트 기기에서만 실행하세요.

## 개발·검증

JDK 21, Gradle Wrapper 9.3.1, Android SDK 37을 사용합니다.

```sh
python3 tools/localize_ko.py --check
python3 tools/test_localize_ko.py
./gradlew :app:assembleDebug
python3 tools/verify_apk.py app/build/outputs/apk/debug/app-debug.apk
```

번역 원문·한국어 대응표는 `localization/ko.json`에 있습니다. `tools/localize_ko.py --apply`는 검토된 원본 1.0.36에 번역을 적용하며 반복 실행해도 결과가 달라지지 않습니다. 검토하지 않은 코드 변경이나 새 중국어 표시 문구가 있으면 검사를 실패시켜 조용히 누락되지 않게 합니다. 새로운 원본 버전으로 갱신할 때에는 코드 차이와 보호 해시도 다시 검토해야 합니다.

검증 결과는 GitHub Actions의 아티팩트와 릴리스에 첨부됩니다. 에뮬레이터 테스트는 기능 스위치를 켜거나 시스템 재시작 명령을 실행하지 않고 화면 탐색만 수행합니다.
